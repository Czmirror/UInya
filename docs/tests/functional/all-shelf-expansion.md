# 素材棚全体の機能試験

対象は docs/specs/all-shelf-expansion.md。2026-11-24、Codexが既存のChromiumヘッドレス版とPlaywrightでビルドを確認した。通常Chromeは起動タイムアウトが2回発生したため、実行環境を切り替えた。

| ケース | 条件 | 確認 | 結果 |
| --- | --- | --- | --- |
| FT1 | AC1 | 4つの棚で追加素材のカードを選ぶ。 | 成功 |
| FT2 | AC2 | 各カードを押した後、保存データのオブジェクト数が増えることを確認する。 | 成功 |
| FT3 | AC3 | SVGとPNGをダウンロードし、SVGの図形とPNGの512 × 512 pxを確認する。 | 成功 |

カードと猫シルエットはSVGからPNGへ描画して目視確認した。Harness必須5件も成功。
次は各棚の配置・書き出しをCIで再現できるようにする。既存の全素材との組み合わせは未確認。
