# ねこ素材棚

「おすすめ」には、はちみつのボタン、ダイアログ、ゲージ、入力欄と、いちごの三毛猫アバターフレームを表示します。「いちご」「はちみつ」「もも」から各5種類を選べます。「クラシック」には従来の素材をまとめています。

各素材は編集可能なSVGです。サムネイルには編集時に読み込むSVGと同じファイルを使います。新しい15点は、承認された画面案を参考に、このリポジトリ用に作図しました。参照したOpenAI Image Genの生成IDは `exec-a060a25f-b3db-4e26-84e4-dfa093cdc931`、`exec-e7fb052e-8947-4f88-a4c3-f6aee0ec8fad`、`exec-ddff7b19-78ff-461c-ab57-bd23079e99b0` です。

「パーツ」には、はちみつ色の丸耳、にっこり目、しましっぽ、肉球、鈴を追加しました。「用途別UI」では完成プレビューから配置でき、文字を含むプリセットは配置後に文字を編集できます。「シルエット」では「ころん猫」の4ポーズを先に表示し、「クラシック」から従来の13ポーズも選べます。追加したパーツとシルエットはUInya向けに作図したSVGです。

「顔」には、テンプレートの三毛猫ボタンとヘッダーなどのマスコットを参考に作図した8種類のSVGを追加しました。輪郭、模様、目、頬などを個別のベクター要素に分けています。「ころん猫」は小さい表示でも姿勢が見分けやすいように、耳、頭、しっぽの形と間隔を調整しました。

顔と組み合わせるパーツには、三毛猫の左右の耳、きらきら目ときょとん目、まめ鼻、鳴き口とちび牙、2種のしっぽ、クリーム色の前足、ふんわりひげ、もも色リボン、ごきげん顔を追加しました。いずれもUInya向けに作図したSVGです。

## マスコットの組み合わせ

マスコット用に24点のSVGを追加しました。「胴体」と「毛柄・頬」でも絞り込めます。新しい顔ベースと三毛模様、目、口、頬は同じ100×100の座標を使うため、サイズを変えずに順に置くと重なります。

- 糸巻きの三毛猫は、顔ベースに左右の三毛模様、弧の目、にっこり口を重ね、前足とピンクの糸巻きを横に置きます。
- 棚の猫は、顔ベースにまる目と頬を重ね、木の棚のふちと前足セットを手前に置きます。
- 眠り猫は、眠る胴体、閉じ目、すやすやの口、まきしっぽを組み合わせます。

追加素材はUInyaのマスコットを参考に作図したSVGです。
