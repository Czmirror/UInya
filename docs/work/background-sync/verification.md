# 背景設定の同期

背景設定欄はキャンバスが確定した背景状態を表示する。背景が空ならチェックを外し、色があればチェックと色コードを一致させる。背景オフ中は最後の色を保持して再オン時に使用する。

FabricCanvasは履歴を確定した時と履歴復元時に背景を通知し、ページ経由でPropertiesPanelへ渡す。通知を受けた表示更新はキャンバス変更イベントを発火しないため、履歴の循環を作らない。PNG書き出し中の一時的な背景変更は通知しない。

## 確認結果

2026-11-23、CodexがPlaywrightとデスクトップChromeで /UInya/ 配下のビルドを確認した。

- 色コード編集、全消去、undoとredoで背景色と設定欄が一致した。
- 背景オフ、undo、redo、再オンでチェック状態と背景が一致した。
- 色の異なる保存データを読み込んだ後、設定欄も保存された色へ戻った。
- 新規生成後、設定欄も生成された背景色へ更新された。
- 各操作後に保存データの背景色と画面の色コード・チェック状態を比較した。
- Harness必須5件が通過した。型検査はエラー0件。既存のCSS警告と依存互換性警告は残る。

既存の挙動を一致させる修正として記録した。次は保存・復元を含むブラウザー回帰試験をCIで実行できるようにする。
