# 全消去の履歴とサイトアイコン

図形が複数あるキャンバスでも、全消去を1回の「元に戻す」で復元し、1回の「やり直す」で再消去できるようにする。変更直前のプロパティ編集は消去前の履歴として確定する。HTMLのサイトアイコンには既存のフッター猫PNGを使用する。

## 検証

2026-11-23、CodexがデスクトップChromeでビルド成果物を /UInya/ 配下から読み込んで確認した。

- 変更前は矩形と円の2個を全消去し、元に戻すと1個しか復元されなかった。
- 修正後は同じ操作で2個を復元し、やり直すと0個になった。
- アイコンの参照先は既存の /brand/sleeping-cat.png。素材の加工や追加はない。
- Harnessの必須5件を実行。型検査はエラー0件。既存のCSS・依存互換性の警告は残る。

背景設定欄とキャンバスの状態同期は別の残課題。次はその同期を優先する。
