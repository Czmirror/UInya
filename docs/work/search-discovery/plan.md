# UInyaの検索向け改善

2026-11-27、ユーザーの「UINyaで検索にヒットするようにしたい」という依頼に基づく。
基点はmainの7ca05fd。素材追加のPR #51とは別の変更として扱う。

- 初期HTMLが空のアプリシェルだったため、静的HTMLの生成を有効にする。FabricCanvasの破棄時にサーバーでも安全に処理できるようにする。
- ページ名、説明、正規URLとOG情報を設定する。
- フッターに利用者が開ける製品説明を追加する。
- sitemap.xmlに公開URLを記載する。GitHub Pagesのサブパスにrobots.txtを置いてもホスト全体の設定にはならないため追加しない。
- 既存の配置・書き出し試験と、初期HTML・サイトマップの確認を行う。

Search Consoleの所有権確認とサイトマップ送信は公開後の作業としてTickTickへ登録した。期限・通知はない。
検索結果への掲載と順位は検索エンジン側の判断で、公開直後の掲載を保証する変更ではない。
