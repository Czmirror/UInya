# 素材棚全体の追加

テンプレート・パーツ・用途別UI・シルエットに各1点を追加する。

| 棚 | 素材 | 登録 |
| --- | --- | --- |
| テンプレート | 肉球のごほうびカード | おすすめのフレーム |
| パーツ | 葉っぱのブローチ | アクセント |
| 用途別UI | ごほうび通知 | カードと編集可能な文字2点 |
| シルエット | おててを上げる猫 | クラシック |

## 受け入れ条件

- AC1 各棚の追加素材を選択できる。
- AC2 各素材をキャンバスに追加できる。
- AC3 追加したキャンバスをSVG・PNGへ出力できる。

SVGはCodexが図形を記述した。外部素材の取り込みはない。リポジトリのMITライセンスに従って配布する。
