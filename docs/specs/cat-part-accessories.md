# 猫パーツのアクセント素材

既存の猫パーツと組み合わせて場面やゲームUIを作るためのSVG小物です。

| 素材ID | 日本語 | 英語 |
| --- | --- | --- |
| accent-yarn-ball | ころころ毛糸玉 | Yarn Ball |
| accent-paw-pincushion | ぷにぷに肉球の針山 | Paw Pincushion |
| accent-cat-scissors | ねこ耳の糸切りばさみ | Cat-ear Thread Snips |
| accent-fish-button | おさかなボタン | Fish-shaped Button |
| accent-stitched-cat-tag | ねこ耳の縫い付けタグ | Stitched Cat Tag |
| accent-paw-pocket | 肉球ポケット | Paw Pocket |
| accent-cat-tape-measure | ころんとねこメジャー | Cat Tape Measure |
| accent-cozy-cat-bed | ふかふか猫ベッド | Cozy Cat Bed |
| accent-fish-cushion | おさかなクッション | Fish Cushion |

## 受け入れ条件

- AC1 「パーツ → アクセント」に上記の素材が表示され、サムネイルを読み込める。表示名は選択中の言語に対応する。
- AC2 各素材をクリックすると、既存のパーツと同様にキャンバスへ配置できる。
- AC3 素材を配置したキャンバスを、有効な寸法でSVG・PNGに書き出せる。

## 素材の出典

上記のSVGはUInya用にCodexがパスと図形を記述したものです。外部素材の取り込みや既存画像の加工はありません。配布にはリポジトリの [MITライセンス](../../LICENSE) が適用されます。
