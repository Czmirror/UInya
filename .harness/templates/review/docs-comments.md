# Review: docs and comments

読む条件: 差分がコード・公開API・設定・ログ・文書を変えた場合。[Review](../review.md)の共通項目と併せて使います。
判断の基準は[Comments](../../rules/core/comments.md)と[Logging](../../rules/core/logging.md)にあります。

- API / 文書 / 設定の整合性:
- ログの機密情報・出力量・level・障害調査情報、コメントの意図・実装との整合性:
- 新規・大きく変更したファイルの冒頭説明（役割・使われ方・前提）と公開シンボルの説明があり、実装と一致するか:
- 変更APIの入力形式・単位・戻り値構造・例外条件を型とコード側の説明から読み取れるか、非自明な処理の理由があるか:
- 変更対象の非自明な変数・定数の用途・単位・値の根拠・状態の更新/reset条件が説明され、実装と一致するか。仮の値や未確認の根拠を仕様として断定していないか（[Comments](../../rules/core/comments.md)）:
